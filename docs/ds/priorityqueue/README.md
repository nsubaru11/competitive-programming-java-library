# Priority Queue

> `lib.ds.priorityqueue` の可変容量優先度キュー、添字ごとにコストを管理する indexed priority queue、両端優先度キューをまとめる。

各キューは追加時のヒープ化を遅延し、優先順が必要な操作の直前にまとめて復元する。走査は内部配列の順であり、優先順ではない。
