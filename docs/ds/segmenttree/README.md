# SegmentTree

> 点更新・区間集計を行うセグメント木、作用素を遅延伝播するセグメント木、一次和と二乗和を法 mod で管理するセグメント木を提供する。永続・2次元・Segment Tree Beats は未実装である。

実装済みの全クラスは非再帰のボトムアップ実装であり、添字は0始まり、区間は半開区間 `[l, r)` とする。範囲外の添字・区間では `IndexOutOfBoundsException` を投げ、`l >= r` の空区間は範囲を検査しない。
単一点の `set` は更新前の値、単一点の `add`・`multiply`・`affine`・`apply` は更新後の値を返し、`fill`・`setAll` は自身を返す。係数を指定するアフィン変換は `affine`、関数や作用素を指定する更新は `apply` とする。区間更新の戻り値は `void` である。詳細は各Guideを参照する。
