# EulerTour（📝 未実装）

## 概要

木の走査順序や入退場時刻を記録し、部分木・パスクエリを配列上で扱うための基盤を提供する予定です。

Euler Tour は一意の列形式を指す名前ではありません。部分木クエリで使う「頂点を各1回記録した DFS 順序」と、木上 Mo で使う「各頂点の入場・退場を記録した長さ `2N` の列」は別形式です。後者では区間内の各頂点出現回数の偶奇がパス頂点集合を表し、LCA が区間外に残る場合は別途扱います。

## 実装クラス

### [EulerTour](../../../src/lib/graph/tree/EulerTour.java)

- **用途**：DFS 順序・部分木区間、または入退場列の提供（提供形式は設計中）
- **設計事項**：
	- 部分木区間用の preorder と、木上 Mo 用の入退場列のどちらを持つか、または両方を提供するか
	- `RootedTree` の HLD 順序 `in/out` と区別できる API 名にする
	- `Tree` / `RootedTree` のどちらを入力として受け取るかを決める
- **想定計算量**：構築 `O(N)`、記憶領域 `O(N)`

## アルゴリズム（データ構造）選択ガイド

部分木の区間問い合わせには各頂点を一度だけ記録する preorder が適します。木上 Mo には入場・退場を記録する列が必要です。通常の LCA 前処理は `RootedTree` を利用します。

## 注意事項

- 本モジュールは雛形のみで、内部ロジックと公開 API は未実装です。
- `RootedTree` の HLD 順序を、一般的な DFS Euler Tour と混同しないでください。
- 木アルゴリズム全体の一覧は [Graph/Tree](../../graph/Tree/README.md) を参照してください。
