## 概要

文字列または文字配列の各位置について、全体の接頭辞との最長共通接頭辞長を表すZ配列を線形時間で構築する。

## 特徴

- `z[i] = LCP(s, s[i:])`
- `z[0]`は入力長
- `String`と`char[]`に対応

## 依存関係

Java標準ライブラリ以外への依存はない。

## API

| メソッド              | 戻り値  | 説明                  |
|-----------------------|---------|-----------------------|
| `getZArray(String s)` | `int[]` | 文字列のZ配列を返す   |
| `getZArray(char[] s)` | `int[]` | 文字配列のZ配列を返す |

## 利用例

```java
import lib.string.matching.ZAlgorithm;

int[] z = ZAlgorithm.getZArray("ababa");
// [5, 0, 3, 0, 1]
```


- [Example.java](../../../test/verify/string/matching/zalgorithm/Example.java)



## 制約・注意事項

- 入力は非空を前提とする。空入力では`z[0]`への書き込み時に例外が発生する。
- 文字列単位はJavaの`char`（UTF-16コードユニット）である。
- パターン検索へ使う場合は、パターンと本文に現れない区切り文字を挟いだ列のZ配列を構築する。

## 性能特性

- 時間計算量: $\mathcal{O}(n)$
- 追加空間: $\mathcal{O}(n)$
