# String Search

## 概要

文字列内のパターンを効率的に検索するためのアルゴリズムを提供します。
これらのアルゴリズムは、テキスト処理、パターンマッチング、DNA配列解析など、様々な分野で活用されています。

## 実装クラス（開発中）

### [KMP (Knuth-Morris-Pratt)](../../../src/lib/string/matching/KMP.java)（未実装）

- **用途**: 文字列内のパターンを線形時間で検索するアルゴリズム
- **特徴**:
	- 前処理によって部分一致テーブルを構築
	- 不一致が発生した場合に、既に一致した情報を利用して効率的にスキップ
	- 最悪の場合でも$\mathcal{O}(n+m)$の時間計算量を保証
- **時間計算量**: $\mathcal{O}(n+m)$、ここでnはテキストの長さ、mはパターンの長さ
- **空間計算量**: $\mathcal{O}(m)$
- **状態**: クラスとTODOコメントのみで、公開APIは未実装です

### [BM (Boyer-Moore)](../../../src/lib/string/matching/BM.java)（未実装）

- **用途**: 実用的に高速な文字列検索アルゴリズム
- **特徴**:
	- 右から左へのパターン比較
	- 不一致文字ヒューリスティックと良好接尾辞ヒューリスティックを使用
	- 平均的にサブリニア（$\mathcal{O}(n)$未満）の性能を示す
- **時間計算量**: $\mathcal{O}(n*m)$（最悪）、平均的には$\mathcal{O}(n/m)$程度
- **空間計算量**: $\mathcal{O}(k)$、ここでkはアルファベットサイズ
- **状態**: クラスとTODOコメントのみで、公開APIは未実装です

### [RollingHash](../../../src/lib/string/matching/RollingHash.java)（未実装）

- **用途**: ハッシュ関数を使用して文字列の部分文字列を効率的に比較するアルゴリズム
- **特徴**:
	- 文字列のハッシュ値を計算し、高速に比較
	- 部分文字列のハッシュ値を定数時間で計算可能
	- 複数のハッシュ関数を使用して衝突確率を低減
- **時間計算量**: 前処理$\mathcal{O}(n)$、クエリ$\mathcal{O}(1)$
- **空間計算量**: $\mathcal{O}(n)$
- **状態**: クラスとTODOコメントのみで、公開APIは未実装です

### [AhoCorasick](../../../src/lib/string/matching/AhoCorasick.java)（未実装）

- **用途**: 複数パターンの同時検索
- **特徴**: Trie、failure link、出力リンクを組み合わせてテキストを線形走査する予定
- **状態**: クラスとTODOコメントのみで、公開APIは未実装です

### [ZAlgorithm](../../../src/lib/string/matching/ZAlgorithm.java)

- **用途**: 文字列の各位置から始まる最長の接頭辞一致を計算するアルゴリズム
- **特徴**:
	- Z配列を構築（Z[i]は文字列と位置iから始まる部分文字列の最長共通接頭辞の長さ）
	- パターンマッチングや周期性の検出に利用可能
	- 線形時間で動作
- **時間計算量**: $\mathcal{O}(n)$
- **空間計算量**: $\mathcal{O}(n)$
- **状態**: 実装済みで、`String` / `char[]` / `int[]` のZ配列を計算できます

## アルゴリズムの選択ガイド

| アルゴリズム | 前処理時間            | 検索時間                               | 空間                  | 適した用途                               |
|--------------|-----------------------|----------------------------------------|-----------------------|------------------------------------------|
| KMP          | $\mathcal{O}(m)$      | $\mathcal{O}(n)$                       | $\mathcal{O}(m)$      | 単一パターンの検索、周期性の検出         |
| Boyer-Moore  | $\mathcal{O}(m+k)$    | $\mathcal{O}(n*m)$〜$\mathcal{O}(n/m)$ | $\mathcal{O}(k)$      | 長いパターン、大きなアルファベット       |
| Rolling Hash | $\mathcal{O}(n)$      | $\mathcal{O}(1)$                       | $\mathcal{O}(n)$      | 高速な部分文字列比較、複数パターンの検索 |
| Z-Algorithm  | $\mathcal{O}(n)$      | $\mathcal{O}(1)$                       | $\mathcal{O}(n)$      | 接頭辞一致の計算、パターンマッチング     |
| Aho-Corasick | $\mathcal{O}(\sum m)$ | $\mathcal{O}(n+occ)$                   | $\mathcal{O}(\sum m)$ | 複数パターンの同時検索                   |

## 注意事項

- 現在利用可能なのは`ZAlgorithm`のみです。KMP / BM / RollingHash / AhoCorasickはTODO雛形です
- 実際の使用前にアルゴリズムの特性と制限を理解することが重要です
