# LCA 利用ガイド

## 概要

[`LCA`](../../../src/lib/graph/tree/LCA.java) は、根付き木における2頂点の最小共通祖先（Lowest Common Ancestor: LCA）を高速に求めるクラスです。
オイラーツアーによる訪問列と深さの変化が $\pm 1$ である性質を利用し（Farach-Colton and Bender のアルゴリズム）、前処理 $\mathcal{O}(N)$、各クエリ $\mathcal{O}(1)$ で回答します。

## 特徴

- 前処理 $\mathcal{O}(N)$、クエリ $\mathcal{O}(1)$ の高速応答
- `RootedTree` のDFS前処理と LCA 用オイラーツアー列の構築は、どちらも明示スタックを使う反復処理
- 半分の対数を基準にしたブロック分割と、深さ増減パターンごとのブロック内 RMQ 表

## 依存関係

- [`RootedTree`](../../../src/lib/graph/tree/RootedTree.java)
- [`MathUtils`](../../../src/lib/math/MathUtils.java)

## 主な機能（メソッド一覧）

### 1. コンストラクタ

| コンストラクタ         | 説明                                                     |
|------------------------|----------------------------------------------------------|
| `LCA(RootedTree tree)` | 根付き木を受け取り、LCA クエリ用のデータ構造を前処理構築 |

### 2. クエリ

| メソッド                 | 戻り値の型 | 説明                                   |
|--------------------------|------------|----------------------------------------|
| `lca(int u, int v)`      | `int`      | 頂点 `u` と `v` の最小共通祖先を返す   |
| `distance(int u, int v)` | `long`     | 頂点 `u` と `v` 間の重み付き距離を返す |

## 利用例

```java
import lib.graph.tree.RootedTree;
import lib.graph.tree.LCA;

// 頂点数 5、根 0 の根付き木（重み付き辺）
RootedTree tree = new RootedTree(5, 0);
tree.add(0, 1, 10);
tree.add(0, 2, 20);
tree.add(1, 3, 5);
tree.add(1, 4, 15);

LCA lca = new LCA(tree);

int ancestor = lca.lca(3, 4); // 1
int rootLca = lca.lca(3, 2);  // 0
long dist = lca.distance(3, 4); // 20
```

## 注意事項

- コンストラクタ呼び出し時に `tree` 内の全辺が追加済みである必要があります。
- 木の頂点番号は `0` から `n - 1` の 0-indexed です。
- `RootedTree` の DFS 情報は最初の参照時に遅延構築され、その後 LCA 用のオイラーツアー列を別途構築します。どちらの走査も再帰呼び出しを使いません。
- 辺は `LCA` の構築前に全て追加してください。`RootedTree` の前処理後は木を変更しないでください。
- パスクエリや部分木更新・k-th ancestor などの多様な操作が必要な場合は、[`HLD`](../../../src/lib/graph/tree/HLD.java) の利用も検討してください。

## パフォーマンス特性

- **前処理時間**: $\mathcal{O}(N)$
- **クエリ時間**: $\mathcal{O}(1)$
- **空間計算量**: $\mathcal{O}(N)$
