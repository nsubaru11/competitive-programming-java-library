# RerootingDP 利用ガイド

## 概要

`RerootingDP` は、全頂点を根とした木DPを実装するときに使う2方向の走査を提供します。子から親へ処理する走査の後、親から子へ処理する走査を行います。DP状態の結合や辺をまたぐ変換は、利用側のコールバックに記述します。

## 特徴

- `RootedTree` の根と親子関係を使い、各非根頂点を子から親の順に1回ずつ処理します。
- 続けて各親子辺を親から子の順に1回ずつ処理します。
- コールバックには頂点と辺の論理IDを渡します。辺IDは `RootedTree.parentEdge(u)` と同じ、追加順の0始まりの無向辺IDです。
- DP状態は配列などで利用側が管理します。コールバック間で同じ配列を書き換えれば、状態ごとに別の配列を用意せずに計算できます。

## 依存関係

- `lib.graph.tree.RootedTree`
- `lib.util.function.IntTernaryConsumer`

## 主な機能（メソッド一覧）

### 1. 走査

| メソッド                                                                                        | 戻り値の型 | 説明                                                                                               |
|-------------------------------------------------------------------------------------------------|------------|----------------------------------------------------------------------------------------------------|
| `run(RootedTree tree, IntTernaryConsumer bottomUpConsumer, IntTernaryConsumer topDownConsumer)` | `void`     | 子から親へのコールバックを全非根頂点に呼び、その後、親から子へのコールバックを全親子辺に呼びます。 |

`bottomUpConsumer` は `(u, parent, parentEdgeId)` を受け取ります。根以外の頂点を、子孫が先に処理される順に呼びます。根には呼びません。

`topDownConsumer` は `(parent, child, edgeId)` を受け取ります。親が先に処理される順に、各親子辺について1回呼びます。

## 利用例

各頂点から全頂点までの距離の合計を計算します。`size[u]` は部分木サイズ、`sum[u]` は走査途中の距離合計または計算済みの全体距離合計です。

```java
int[] size = new int[n];
Arrays.fill(size, 1);
long[] sum = new long[n];

RerootingDP.run(tree, (u, parent, edgeId) -> {
	size[parent] += size[u];
	sum[parent] += sum[u] + size[u];
}, (parent, child, edgeId) -> {
	sum[child] = sum[parent] + n - 2L * size[child];
});
```

呼び出し後、`sum[u]` に各頂点 `u` から全頂点までの距離の合計が入ります。辺の重みや属性が必要なら、コールバックに渡される論理辺IDを使って `tree.cost(edgeId)` などを参照します。

## 注意事項

- 全ての辺を追加した後に呼び出してください。`run` は `RootedTree` の遅延前処理を行います。
- コールバックの引数順は、下から上が `(頂点, 親, 親辺ID)`、上から下が `(親, 子, 辺ID)` です。
- `bottomUpConsumer` は根に対して呼ばれません。根の初期状態や最終状態が必要な場合は、呼び出し側で設定してください。
- 結合の単位元、結合順、辺をまたぐ変換、頂点値の取り込みは利用側の責任です。問題に応じた全方位DPの漸化式を正しく実装してください。
- コールバックは各辺につき上下それぞれ1回呼ばれます。コールバック内で配列を上書きする場合は、上記の処理順を前提に状態の生存期間を管理してください。
- 木の構造を `run` のコールバック内で変更しないでください。

## パフォーマンス特性

- 走査時間: `O(N)`。各頂点と各辺を定数回処理します。
- `RerootingDP` 自身の追加領域: `O(1)`。`RootedTree` の内部配列を再利用します。
- `RootedTree` の前処理が未実行の場合、その初回構築に `O(N)` 時間・`O(N)` 領域を使います。

バージョン番号は2桁で管理します：

- 1桁目（メジャーバージョン）: メソッドの追加や機能拡張があった場合に更新
- 2桁目（マイナーバージョン）: 誤字修正、バグ修正、マイクロ高速化などの小さな更新があった場合に更新
