## 概要

`BellmanFord`は、負辺を含む`Graph`に対して単一始点または複数始点の最短経路を計算する静的ユーティリティクラスである。

## 特徴

- `DirectedGraph`と`UndirectedGraph`の両方に対応
- 始点から到達可能な負閉路を検出
- 負閉路から到達可能な頂点まで影響範囲を伝播
- 有限距離、到達不能、負閉路の影響を1つの距離配列で表現
- 負閉路の影響を受けない頂点では経路復元が可能
- `BFS`、`Dijkstra`、`ZeroOneBFS`と共通の`PathResult`を返す

## 依存関係

- [`Graph`](../core/GraphGuide.md)

## API

### 1. 計算

| メソッド                          | 戻り値の型   | 説明                                                         |
|-----------------------------------|--------------|--------------------------------------------------------------|
| `solve(Graph graph, int s)`       | `PathResult` | 始点`s`から全頂点への距離、親、負閉路の影響を計算            |
| `solve(Graph graph, int... s)`    | `PathResult` | 複数始点のいずれかから全頂点への距離、親、負閉路の影響を計算 |
| `dist(Graph graph, int s)`        | `long[]`     | 始点`s`から全頂点への距離を返す                              |
| `dist(Graph graph, int... s)`     | `long[]`     | 複数始点のいずれかから全頂点への距離を返す                   |
| `dist(Graph graph, int s, int g)` | `long`       | 始点`s`から終点`g`への距離を返す                             |
| `path(Graph graph, int s, int g)` | `int[]`      | 始点`s`から終点`g`への経路を返す                             |

### 2. `PathResult`

| メソッド           | 戻り値の型 | 説明                                    |
|--------------------|------------|-----------------------------------------|
| `distTo(int v)`    | `long`     | 頂点`v`への距離                         |
| `reachable(int v)` | `boolean`  | 頂点`v`へ到達可能か判定                 |
| `parent(int v)`    | `int`      | 最短経路上の親                          |
| `pathTo(int v)`    | `int[]`    | 始点から`v`への経路。復元不能なら`null` |

`PathResult`からは`hasNegCycle`、始点配列`s`、距離配列`dist`、親配列`parent`も直接参照できる。`hasNegCycle`は、いずれかの始点から到達可能な負閉路がある場合に`true`である。詳細は[PathResultGuide.md](PathResultGuide.md)を参照すること。

## 制約・注意事項

- 到達不能な頂点の距離は`Long.MAX_VALUE`である。
- 到達可能な負閉路上の頂点と、そこから到達可能な頂点の距離は`Long.MIN_VALUE`である。
- `reachable(v)`は距離が`Long.MIN_VALUE`でも`true`を返す。
- 到達不能または負閉路の影響下では、`parent(v)`は`-1`、`pathTo(v)`は`null`である。
- 始点から到達できない負閉路は、その始点の`hasNegCycle`と距離配列に影響しない。
- 複数始点版では、各始点を距離0として負閉路の影響範囲を判定する。

## 性能特性

- 時間計算量: $\mathcal{O}(VE)$
- 負閉路の影響伝播: $\mathcal{O}(V + E)$。全体の$\mathcal{O}(VE)$に含まれる
- 追加領域: $\mathcal{O}(V)$
