## 概要

`BFS`は、辺の重みを1として扱う`Graph`に対して、幅優先探索で単一始点または複数始点の最短経路を計算する静的ユーティリティクラスである。

## 特徴

- `DirectedGraph`と`UndirectedGraph`の両方に対応
- 全頂点の距離と親を返す`solve`
- 全頂点または指定した終点の距離を返す`dist`
- `PathResult`による経路復元
- プリミティブ配列だけを使う`O(V + E)`の探索

## 依存関係

- [`Graph`](../core/GraphGuide.md)
- [`PathResult`](PathResultGuide.md)

## API

### 1. 計算結果を返すメソッド

| メソッド                       | 戻り値の型   | 説明                                           |
|--------------------------------|--------------|------------------------------------------------|
| `solve(Graph graph, int s)`    | `PathResult` | 始点`s`から全頂点への距離と親を計算            |
| `solve(Graph graph, int... s)` | `PathResult` | 複数始点のいずれかから全頂点への距離と親を計算 |

### 2. 距離を返すメソッド

| メソッド                          | 戻り値の型 | 説明                                       |
|-----------------------------------|------------|--------------------------------------------|
| `dist(Graph graph, int s)`        | `long[]`   | 始点`s`から全頂点への距離を返す            |
| `dist(Graph graph, int... s)`     | `long[]`   | 複数始点のいずれかから全頂点への距離を返す |
| `dist(Graph graph, int s, int g)` | `long`     | 始点`s`から終点`g`への距離を返す           |

### 3. 経路を返すメソッド

| メソッド                          | 戻り値の型 | 説明                               |
|-----------------------------------|------------|------------------------------------|
| `path(Graph graph, int s, int g)` | `int[]`    | 始点`s`から終点`g`への頂点列を返す |

## 制約・注意事項

- 辺の重みは参照せず、すべての辺を距離1として扱う。重みが0または1の場合は`ZeroOneBFS`を使用すること。
- 到達不能な頂点の距離は`Long.MAX_VALUE`である。
- 複数始点版では、各始点の距離を0として同時に探索する。
- `path`と`pathTo`は始点と終点を含む頂点列を返し、到達不能な場合は`null`を返す。
- 結果の`hasNegCycle`は常に`false`である。

## 性能特性

- `solve`、`dist(graph, s)`、`path`: $\mathcal{O}(V + E)$
- `dist(graph, s, g)`: 最悪$\mathcal{O}(V + E)$。終点を発見した時点で探索を終了
- 追加領域: $\mathcal{O}(V)$
- `pathTo`: 経路長に比例する配列を作成
