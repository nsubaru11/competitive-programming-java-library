# Dice

[`Dice`](../../../src/lib/util/Dice.java)は、6面体の向きと回転操作を表します。

## 主な機能

- `u()` / `d()` / `f()` / `b()` / `l()` / `r()`: 各面の値を取得
- `rotateUR()`: 上面と右面を通る方向へ回転
- `rotateFR()`: 前面と右面を通る方向へ回転
- `rotateUF()`: 上面と前面を通る方向へ回転

## 注意事項

- 回転メソッドは内部配列を直接変更します。
- record componentの`dice`は配列参照をそのまま返します。
