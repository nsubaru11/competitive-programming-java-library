# ModLong

## 概要

`ModLong`は`long`の`value`と`mod`を保持する、`Number`を継承した不変クラスです。演算は新しい`ModLong`を返します。

## API

| メソッド                                  | 説明                           |
|-------------------------------------------|--------------------------------|
| `ModLong(long value, long mod)`           | 指定値と法で作成               |
| `add` / `sub` / `mul`                     | 同じ法の値との加減乗算         |
| `div`                                     | Fermatの小定理による除算       |
| `pow(int exp)`                            | 非負整数乗                     |
| `value()` / `mod()`                       | 値と法を返す                   |
| `intValue()` / `longValue()` ほか         | `Number`として値を変換         |

## 注意事項

- 値はコンストラクタで正規化されません。
- `value`と`mod`は`public final`フィールドとしても参照できます。
- 二項演算は両辺の法が等しいことを前提とします。
- `mul`、`div`、`pow`は中間積が`long`に収まる範囲を前提とします。現在の実装はlong全域の法を扱うMontgomery乗算等を備えていません。
- `div`は法が素数で、除数が0でないことを前提とします。
