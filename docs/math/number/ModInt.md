# ModInt

## 概要

`ModInt`は`int`の`value`と`mod`を保持する、`Number`を継承した不変クラスです。演算は新しい`ModInt`を返します。

## API

| メソッド                                  | 説明                           |
|-------------------------------------------|--------------------------------|
| `ModInt()`                                | 値0、法998244353               |
| `ModInt(int value)`                       | 指定値、法998244353            |
| `ModInt(int value, int mod)`              | 指定値と法で作成               |
| `add` / `sub` / `mul`                     | 同じ法の値との加減乗算         |
| `div`                                     | Fermatの小定理による除算       |
| `pow(int exp)`                            | 非負整数乗                     |
| `value()` / `mod()`                       | 値と法を返す                   |
| `intValue()` / `longValue()` ほか         | `Number`として値を変換         |

## 注意事項

- 値はコンストラクタで正規化されません。
- `value`と`mod`は`public final`フィールドとしても参照できます。
- 二項演算は両辺の法が等しいことを前提とします。
- `div`は法が素数で、除数が0でないことを前提とします。
